Design a desktop homepage for a Russian merchandise manufacturing company called “Тюменская фабрика мерча / ТФМ”.

Goal

Create a high-fidelity homepage design for a merch producer that brands products for businesses, teams, events, and organizations. The page should feel modern, premium, bold, and commercially strong. It should look like a real website concept ready for presentation to a client.

Core visual direction

Use a style inspired by:

editorial e-commerce
Swiss grid
neo-brutalist / bold typography
minimal monochrome merch branding
industrial / streetwear visual language

The page must feel:

clean
bold
structured
premium
product-focused
modern
visually striking, but still functional and business-oriented

Do not make it colorful or playful. Avoid generic SaaS styling.

Color palette

Use a restrained palette:

warm light gray / off-white background
black / near-black text
shades of gray for surfaces and dividers
one bright acid yellow / neon yellow accent for CTA buttons, numbers, and selected highlights
Typography

Use strong bold sans-serif typography.
The typography should be one of the main visual tools:

very large bold headings
medium clean body text
compact labels / editorial micro-copy
strong hierarchy
high contrast
Layout and style rules
Use a clean desktop layout around 1440 px width
Use a strong grid and consistent spacing
Mix large headlines with smaller editorial annotations
Use rounded corners subtly or keep shapes mostly clean and restrained
Use high-quality monochrome product imagery
The design should rely heavily on merch product compositions: cap, hoodie, tote bag, thermos / bottle, patch, T-shirt, outerwear, accessories
Add subtle editorial details, graphic captions, and small labels
The page should feel like a serious modern merch brand, not a template
Keep the interface realistic and usable
Build a complete homepage, not just a hero block

Important creative guidance

Do not design this like a generic SaaS site or like a colorful agency template.

Instead:

make it feel like a merch brand with strong art direction
combine business clarity with editorial visual impact
prioritize typography + merch product compositions
keep the page high-end, clean, and convincing
make sure the design looks like a real client-facing homepage concept
